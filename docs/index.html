ShotPark으로 캡처하고 표시한 실제 결과물. ⌘⇧9를 누르고 지도 위를 드래그한 뒤, 원·화살표·텍스트를 넣고 ⌘C로 복사하면 끝.

기능

⌨️

단축키 한 번, 드래그 한 번

기본 ⌘⇧9. 화면이 어두워지면 드래그로 영역을 잡고, 핸들로 크기 조절, 안쪽 드래그로 이동. 픽셀 크기가 실시간으로 표시됩니다.

✏️

바로 주석

펜 · 선 · 화살표 · 사각형 · 타원 · 마커 · 텍스트, 10색 팔레트, 실행 취소. 텍스트는 크기 5단계와 그림자 · 외곽선 · 배경(마스킹) 스타일 선택. 화면에 보이는 그대로 내보냅니다.

📋

복사 · 저장 · 공유

⌘C로 클립보드, ⌘S로 지정 폴더에 즉시 PNG 저장, ⌘⇧S로 Claude · Slack · 카카오톡 또는 macOS 공유 시트.

🖥️

Retina · 다중 모니터

ScreenCaptureKit으로 각 디스플레이의 실제 해상도 그대로 캡처합니다. 모니터가 몇 대든 같은 방식.

⚙️

내 맘대로 설정

캡처 단축키, 저장 폴더, 바로 저장 여부를 설정 창에서 변경. 로그인 시 자동 실행 옵션.

🪶

가볍고 투명하게

Swift/AppKit 파일 9개, 외부 라이브러리 0개. Dock에 안 뜨고 메뉴 막대에만 있습니다. 온라인 업로드 없음.

설정 창 (⌘,). 단축키 박스를 클릭하고 원하는 조합을 누르면 바로 적용됩니다.

설치

1

다운로드하고 응용 프로그램 폴더로

최신 릴리즈에서 ShotPark-x.y.z.zip을 받아 압축을 풀고 ShotPark.app을 응용 프로그램 폴더로 옮깁니다.

2

처음 한 번, Gatekeeper 통과

ShotPark은 Apple 개발자 서명이 없는 오픈소스 앱이라 처음 열 때 macOS가 "확인할 수 없는 개발자"라며 막습니다. 아래 둘 중 편한 방법으로 한 번만 열어 주면 그 뒤로는 묻지 않습니다.

방법 A — 터미널 한 줄 (가장 확실):

xattr -d com.apple.quarantine /Applications/ShotPark.app

방법 B — 설정에서 허용: 앱을 한 번 더블클릭해 경고를 닫은 뒤, 시스템 설정 → 개인정보 보호 및 보안 맨 아래에 나타나는 "그래도 열기"를 누릅니다.

3

화면 기록 권한 허용

첫 캡처(⌘⇧9) 때 아래 창이 뜹니다. "시스템 설정 열기"를 누르고 목록에서 ShotPark을 켜 주세요. 켠 뒤 앱을 한 번 종료했다가(메뉴 막대 아이콘 → ShotPark 종료) 다시 실행하면 바로 캡처됩니다.

소스에서 직접 빌드하면 2단계가 필요 없습니다. Xcode Command Line Tools만 있으면 됩니다.

git clone https://github.com/suseokpark/shotpark.git
cd shotpark
./build.sh --install

자주 묻는 질문

단축키를 눌러도 아무 일도 안 일어나요

화면 기록 권한이 아직 없는 경우입니다. 메뉴 막대 아이콘 → "화면 기록 권한 설정…"에서 ShotPark을 켜고 앱을 재실행하세요. 다른 앱이 같은 전역 단축키를 쓰고 있다면 설정에서 조합을 바꿔 보세요.

"손상되었기 때문에 열 수 없습니다"라고 떠요

다운로드한 파일에 붙는 격리 속성 때문입니다. 설치 2단계의 xattr -d com.apple.quarantine /Applications/ShotPark.app으로 해제하면 됩니다.

업데이트했더니 화면 기록 권한을 다시 물어봐요

정상입니다. 서명이 바뀐 새 빌드는 macOS가 새 앱으로 취급해서 한 번 더 묻습니다. 켜 주고 앱을 재실행하면 됩니다.

Slack / 카카오톡 공유는 어떻게 동작하나요?

이미지를 클립보드에 복사한 뒤 해당 앱에 파일을 넘깁니다. Slack처럼 파일을 받는 앱은 업로드 창이 바로 뜨고, 받지 않는 앱은 앞으로 올라오기만 하므로 ⌘V로 붙여넣으면 됩니다.

Intel 맥은요?

릴리즈 바이너리는 Apple Silicon 전용입니다. build.sh에서 --arch arm64를 지우고 직접 빌드하면 Intel에서도 돌아갑니다.

온라인 링크로 공유할 수 있나요?

아니요. 의도적으로 모든 처리를 로컬에서만 합니다. 공유는 클립보드, 파일, macOS 공유 시트를 통해서만 이뤄집니다.

English

ShotPark is a region screenshot tool for macOS, built natively for Apple Silicon in Swift/AppKit with zero dependencies. Hotkey (default ⌘⇧9) → drag a region → annotate (pen, line, arrow, rectangle, ellipse, marker, text) → ⌘C to copy, ⌘S to save PNG straight into your chosen folder, ⌘⇧S to share to Claude / Slack / KakaoTalk or the macOS share sheet. Multi-monitor, Retina capture, menu-bar only, configurable hotkey and save folder.

Install: download ShotPark-x.y.z.zip from the latest release, move the app to Applications, clear the quarantine flag once (xattr -d com.apple.quarantine /Applications/ShotPark.app, or allow it under System Settings → Privacy & Security), then grant Screen Recording permission on first capture and relaunch. Or build from source with ./build.sh --install. Requires macOS 13+ on Apple Silicon. The UI is currently in Korean. MIT licensed.
