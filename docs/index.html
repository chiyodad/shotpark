ShotPark

단축키 한 번으로 영역을 선택하여 캡처하고, 바로 주석을 달아 빠르게 공유하세요.
Apple Silicon과 Intel 맥에서 네이티브로 동작하고, Windows 버전도 있습니다.

Windows에서 PicPick·Lightshot을 쓰셨다면, macOS에서는 ShotPark.

⬇ macOS용 다운로드 ⬇ Windows용 다운로드 소스 보기
brew install --cask chiyodad/tap/shotpark
Windows 10/11 · 관리자 권한 없이 설치 · 설치 없이 쓰려면 휴대용 zip (ARM)
무료 · MIT 라이선스 · 캡처는 모두 로컬에서 처리, 어디에도 업로드하지 않습니다

⌘⇧9 → 드래그로 영역 선택 → 사각형·화살표·텍스트·번호 도장 → 개인정보는 모자이크 → ⌘C로 복사하면 끝!

무료로 쓰시다가 마음에 드시면 커피 한 잔으로 응원해 주세요 ☕

기능

⌨️

단축키 한 번, 드래그 한 번

기본 ⌘⇧9. 화면이 어두워지면 드래그로 영역을 잡거나, 창을 클릭해 통째로 선택(가려진 부분까지 그 창만, 둥근 모서리·그림자 포함). Space를 누르면 창 선택 모드. 핸들로 크기 조절, 안쪽 드래그로 이동, 방향키로 1px 미세 조정. 픽셀 크기가 실시간으로 표시됩니다.

✏️

바로 주석

화살표 · 도형 · 텍스트 · 번호 · 도장 · 모자이크를 캡처한 자리에서 바로. 그린 뒤에도 옮기고, 지우고, 굵기·색을 다시 바꿀 수 있습니다.

📋

복사 · 저장 · 공유

⌘C로 클립보드에 복사, ⌘⇧C로 텍스트·QR 추출, ⌘⇧P로 화면에 고정, 꾸미기를 켜면 여백·그림자·둥근 모서리까지, ⌘S로 지정 폴더에 PNG 바로 저장, ⌘⇧S로 Claude · ChatGPT · Gemini · Slack · 카카오톡 또는 macOS 공유 시트로 보내기.

🗂️

클립보드 이미지 기록

⌃⌘V를 누르면 최근 복사한 이미지 30개가 썸네일로 보입니다. 다른 앱에서 복사한 이미지도 모이고, 클릭하면 다시 복사되며, 끌어다 놓으면 다른 앱에 바로 들어갑니다. 내 맥에만 저장됩니다.

🖥️

Retina · 다중 모니터

ScreenCaptureKit으로 각 디스플레이의 실제 해상도 그대로 캡처합니다. 모니터가 여러 대여도 똑같이 동작합니다.

⚙️

내 맘대로 설정

캡처·도구 단축키, 저장 폴더, 바로 저장 여부, 주석 색상 팔레트, 꾸미기, 클립보드 기록을 설정 창에서 바꿀 수 있습니다. 로그인 시 자동 실행도 지원하고, 새 버전이 나오면 메뉴에서 알려 줍니다. 화면 언어(한국어·영어)는 macOS 설정을 따릅니다.

설정 창 (⌘,). 단축키 박스를 클릭하고 원하는 조합을 누르면 바로 적용됩니다. 클립보드·모자이크·텍스트 추출·고정 단축키, 저장 폴더와 저장·복사 연동, 주석 색상, 꾸미기(그림자·둥근 모서리), 클립보드 기록도 여기서 설정합니다.

픽픽 · 라이트샷과의 차이점

한국에서 널리 쓰이는 캡처 프로그램 픽픽은 Windows 전용이라 맥 버전이 없고, 라이트샷의 맥 앱은 Intel 빌드라 Apple Silicon 맥에서는 Rosetta가 필요합니다. ShotPark은 두 프로그램의 "단축키 → 드래그 → 바로 주석 → 복사" 흐름을 맥 네이티브로 그대로 옮긴 앱입니다.

⚡️

손에 익은 그대로

단축키 → 드래그 → 주석 → ⌘C. PicPick이나 Lightshot을 써 봤다면 따로 배울 게 없습니다.

🍎

요즘 맥에 맞게

Apple Silicon · Intel 유니버설 네이티브 앱. Rosetta·Electron·Java 없이 Swift로 만든 가벼운 앱입니다.

🧰

주석은 더 많이

Lightshot의 기능에 더해 모자이크·블러, 텍스트 추출(OCR), 도장·서명, 도형 채우기를 지원하고, 그린 뒤에도 옮기고 고치고 지울 수 있습니다.

설치

1

설치 방법

1) Homebrew (추천)

brew install --cask chiyodad/tap/shotpark

2) CLI — 최신 버전을 받아 응용 프로그램 폴더에 넣고, 격리 속성을 해제한 뒤 실행합니다:

curl -fsSL https://shotpark.site/install.sh | sh

3) 다운로드 — 최신 릴리즈에서 ShotPark-x.y.z.zip을 받아 압축을 풀고 ShotPark.app을 응용 프로그램 폴더로 옮깁니다.

처음 한 번, Gatekeeper 통과하기 — ShotPark은 Apple 개발자 서명이 없는 오픈소스 앱이라 처음 열 때 macOS가 "확인할 수 없는 개발자"라며 막습니다. 아래 둘 중 편한 방법으로 한 번만 열어 주면 그 뒤로는 묻지 않습니다. Homebrew · CLI · 소스 빌드로 설치했다면 필요 없습니다.

방법 A — 터미널 한 줄 (가장 확실):

xattr -d com.apple.quarantine /Applications/ShotPark.app

방법 B — 설정에서 허용: 앱을 한 번 더블클릭해 경고를 닫은 뒤, 시스템 설정 → 개인정보 보호 및 보안 맨 아래에 나타나는 "그래도 열기"를 누릅니다.

4) 소스에서 빌드 — Xcode Command Line Tools만 있으면 됩니다.

git clone https://github.com/chiyodad/shotpark.git
cd shotpark
./build.sh --install
2

화면 기록 권한 부여

처음 실행하면 아래 창이 뜹니다. "시스템 설정 열기"를 누르고 목록에서 ShotPark을 켜 주세요. 켠 뒤 앱을 한 번 종료했다가(메뉴 막대 아이콘 → ShotPark 종료) 다시 실행하면 바로 캡처됩니다.

W

Windows

ShotPark-Windows-Setup.exe를 받아 실행하세요. 관리자 권한 없이 내 계정에만 설치되고, 시작 메뉴에 등록되며, 설치를 마치면 바로 실행됩니다. 일반 PC와 ARM PC 모두 같은 파일입니다. .NET 설치나 화면 기록 권한 허용 없이 Ctrl+Shift+9로 바로 캡처할 수 있고, 제거는 Windows 설정 → 앱에서 합니다.

설치 없이 쓰려면 휴대용 zip(x64 · ARM64)을 받아 원하는 폴더에 풀고 ShotPark.exe를 실행하세요.

  • SmartScreen 경고 — 코드 서명이 없는 앱이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행을 누르세요.
  • 트레이 아이콘 — Windows 11은 새 아이콘을 작업 표시줄 오른쪽 ^ 안에 숨겨 둡니다. 거기서 ShotPark 아이콘을 작업 표시줄로 끌어다 놓으면 늘 보입니다. 아이콘을 클릭해도 캡처됩니다.
  • 자동 실행 — 설치 프로그램에서 기본으로 켜져 있습니다. 나중에 트레이 아이콘 → 설정에서 끄고 켤 수 있습니다.
  • PrtSc 키로 쓰려면 — Windows 11은 PrtSc를 캡처 도구가 먼저 가져갑니다. 설정 → 접근성 → 키보드에서 "Print Screen 키를 사용하여 화면 캡처 열기"를 끈 뒤, ShotPark 설정에서 단축키를 PrtSc로 지정하세요.
  • 저장 위치 — Ctrl+S는 기본으로 사진 폴더에 바로 저장합니다. 트레이 아이콘 → 설정에서 바꿀 수 있습니다.

맥 버전과 기능이 같습니다. 텍스트 추출은 Windows 내장 OCR을 쓰므로 해당 언어(한국어·영어·일본어·중국어)가 Windows에 설치되어 있어야 하고, 공유는 이미지를 클립보드에 복사한 뒤 앱을 앞으로 불러오므로 Ctrl+V로 붙여넣으면 됩니다.

자주 묻는 질문

Windows에서도 쓸 수 있나요?

네. 위의 Windows 다운로드 버튼(설치 프로그램)이나 휴대용 zip으로 받으세요. 창 선택, 모든 주석 도구, 텍스트·QR 추출, 화면에 고정, 꾸미기, 공유, 클립보드 이미지 기록까지 맥과 같은 기능을 지원합니다. 단축키는 ⌘ 대신 Ctrl을 쓰며, 캡처 기본값은 Ctrl+Shift+9입니다. 위 단축키 표의 Windows 열을 참고하세요.

단축키를 누르면 "화면 기록 권한이 필요합니다" 창만 떠요

아직 화면 기록 권한이 없어서입니다. 창의 시스템 설정 열기(또는 메뉴 막대 아이콘 → "화면 기록 권한 설정…")를 눌러 ShotPark을 켜고 앱을 다시 실행하세요.

단축키를 눌러도 아무 반응이 없어요

다른 앱이 같은 단축키를 쓰고 있을 가능성이 큽니다. 이 경우 ShotPark이 단축키를 등록하지 못했다는 알림을 띄웁니다. 설정에서 다른 조합으로 바꾸거나, 메뉴 막대 아이콘 → 영역 캡처로 시작하세요.

"손상되었기 때문에 열 수 없습니다"라고 떠요

다운로드한 파일에 붙는 격리 속성 때문입니다. 설치 방법 3) 다운로드 아래의 xattr -d com.apple.quarantine /Applications/ShotPark.app으로 해제하면 됩니다.

업데이트했더니 화면 기록 권한을 다시 물어봐요

정상입니다. 서명이 바뀐 새 빌드는 macOS가 새 앱으로 취급해서 한 번 더 묻습니다. 권한을 켜고 앱을 다시 실행하면 됩니다.

Slack / 카카오톡 / ChatGPT / Gemini 공유는 어떻게 동작하나요?

이미지를 클립보드에 복사한 뒤 해당 앱에 파일을 넘깁니다. Slack처럼 파일을 받는 앱은 업로드 창이 바로 뜨고, 받지 않는 앱은 앞으로 올라오기만 하므로 ⌘V로 붙여넣으면 됩니다. ChatGPT·Gemini 앱이 없으면 웹이 열리니 거기서 ⌘V 하세요.

픽픽이나 라이트샷을 쓰다 왔는데, 뭐가 같고 뭐가 다른가요?

같은 것: 전역 단축키 → 드래그로 영역 → 그 자리에서 화살표·사각형·텍스트 → 클립보드 복사. 픽픽의 "영역 캡처 후 바로 편집", 라이트샷의 "캡처 즉시 주석"과 같은 흐름이고, 창을 클릭하면 창 전체가 잡히는 것도 같습니다. 다른 것: 단축키 기본값이 ⌘⇧9이고(설정에서 원하는 조합으로 변경), 픽픽의 자·색상 추출·화이트보드·스크롤 캡처는 없습니다.

긴 화면(스크롤) 캡처는 되나요?

아직은 안 됩니다. 긴 웹페이지는 브라우저 기능으로 전체 페이지를 캡처할 수 있습니다(Chrome·Edge: ⌥⌘I → ⌘⇧P → "Capture full size screenshot", Firefox: 우클릭 → 스크린샷 찍기 → 전체 페이지 저장). 앱 화면의 스크롤 캡처가 필요하면 이 이슈에 👍를 눌러 주세요.
